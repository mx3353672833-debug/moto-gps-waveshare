# MOTO GPS 产品说明与技术参数

MOTO GPS 在圆屏上显示路线、下一个路口的动作和距离，也提供马表、航向与音乐控制。
当前软件开发使用微雪成品板和 iPhone；自研 A1 是另一个已经保存工程文件的硬件候选。
以下数值来自仓库的板级说明、A1 状态单和 V3 机械规格。标为设计值的项目尚未转为量产实测值。

## 两个硬件版本

| 项目 | 当前 Waveshare 样机 | 自研 H0175 EVT A1 候选 |
| --- | --- | --- |
| 主控 | ESP32-S3，微雪 ESP32-S3-Touch-AMOLED-1.75C 成品板 | ESP32-S3-WROOM-1U-N16R8 |
| 圆屏 | 1.75 英寸，466 × 466 AMOLED，CO5300 | 华夏彩光 H0175Y003AMT003 V1，1.75 英寸，466 × 466，CO5300 QSPI |
| 触控 | CST9217，微雪官方 BSP | CST820，31 Pin 屏幕接口 |
| 显示格式 | 共享 LVGL，466 × 466 RGB565 | 同分辨率设计目标，板级驱动需要独立适配 |
| 导航定位 | iPhone Core Location；手机计算导航状态，BLE 下发 | 历史方案集成 LC76GABMD 独立 GNSS，通过手机热点联网 |
| 运动与航向 | 板载 QMI8658；手机行进航向 | QMI8658A + IIS2MDCTR；整车磁校准待验证 |
| 电源 | 微雪板载 AXP2101 | BQ25628E + TPS63070 + TUSB320LAI 设计链路 |
| 板体 | 成品板外形以官方板资料为准 | 名义 Ø52 mm、四层板 |
| 当前状态 | 已建立固件与 iOS 联调链路，持续实机测试 | 原理图、PCB 和制造审阅资料已生成，尚未生产放行 |

## 软件与使用功能

| 功能 | 当前实现 |
| --- | --- |
| 目的地搜索 | 手机位置偏置搜索；附近无结果时回退区域或全国搜索；最多保存 8 条最近地点 |
| 路线预览 | MapKit 全程预览，最多 3 条高德候选路线，比较时间、里程和路况后手动开始 |
| 导航 | 共享 C++ 路线推进、到达判断、连续偏航确认、重算、过期响应丢弃与路况刷新 |
| 圆屏地图 | 白色选中路线，车头朝上；灰色道路与建筑由局部地图窗口提供 |
| 离线底图 | 济南 SQLite 矢量包：47,468 条道路、26,702 个建筑；由手机裁剪附近窗口发送 |
| 页面操作 | 左右滑动切换导航、马表、指南针和可选音乐页；指示点 5 秒后隐藏 |
| 音乐 | Apple Music 上一首、播放/暂停、下一首与曲目状态 |
| 通信 | BLE v1；CRC、分片重组、心跳、会话校验和双阶段握手 |
| 开关机 | 黑底 Logo 启动；微雪 PWR 按住 3 秒软件关机、4 秒 PMIC 硬件兜底配置 |

离线底图负责环境显示，不表示全国离线导航。正常路线规划与重算使用在线网关；
真实导航不会自动转成演示路线。指南针当前主要表达行进航向，停车真北与通用第三方音乐控制尚待扩展。
限速牌仅在存在可信数据时显示；首图中的数字是效果示意。

## 核验记录与待验证参数

A1 状态单记录 93 个 PCB 封装、458 个焊盘、1555 段走线、189 个过孔，
KiCad 10.0.6 的 ERC、DRC、未连接和原理图一致性错误均为 0。
这是归档电气规则检查结果，实体屏幕/FPC、电源切换、RF、散热、装车振动与卡口仍需测试。

续航、整机重量、防水等级、户外亮度、GNSS/罗盘精度和最终实测帧率尚无统一放行数据，
本页不填写推测值。软件的锁屏后台与长时间 BLE 表现以[当前已知问题](KNOWN_ISSUES.md)为准。
