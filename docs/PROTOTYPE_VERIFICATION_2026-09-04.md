# 微雪 + iPhone 样机交付与验证记录（2026-09-04）

## 交付结论

- 当前 iOS App 测试版提供明确标注的内置导航演示；正常/生产导航只使用真实 Core Location、真实 POI 和线上路线。
- iPhone 负责定位、高德路线、实时路况、偏航重算和导航状态；ESP32 负责触摸与 466 × 466 圆屏显示。
- ESP32 固件已接入微雪 1.75C 官方 BSP、CO5300、CST9217、NimBLE 与共享 LVGL 源码。
- BLE v1 的 UUID、帧、CRC、分片、握手、心跳、ACK 和页面命令已经冻结。
- 原生 App 已实现按手机当前位置优先的附近地点搜索；近场无结果或无定位时由网关回退全国/区域文本搜索。
- BLE 恢复连接、事件乱序、握手可靠写入与重试、旧会话过滤和失败退避问题已修正；同一 iPhone 已连续 3 次冷启动一次完成两阶段握手，协商帧长均为 182，观察期无失败/成功跳变。长时间锁屏/反复断电验证仍待完成。
- iOS 与 ESP32 均已接入黑底白色 `MOTO GPS` 启动画面；ESP32 Logo 在既有 1.25 秒启动节奏内淡入、停留、淡出。圆屏页面指示点 5 秒无操作自动隐藏，导航页长按可开关本机演示路线。
- 导航页只显示大号距离数字 + 单位，不显示说明性距离标题；没有真实路线且未开启演示时隐藏动作图标、距离、路线进度和限速牌，不出现误导性的直行 `0 m`。
- Web、ESP32 和 iOS 离线回退使用济南真实道路：白色选中路线与灰色周边道路均来自可核验的 OpenStreetMap way，保留 `© OpenStreetMap contributors` 署名并遵守 ODbL，坐标与道路明细见 [演示数据说明](../shared/demo_fixture/README.md)。iOS 在线演示与正式导航才实时请求高德，响应不固化进演示夹具。
- 普通高德路线接口不提供完整周边道路网。正式在线道路层仍需开通高德“交通态势查询”高级 API，并在车载/智能硬件投射前取得明确书面授权；当前 OSM fixture 只用于可重复演示。
- 线上高德网关健康检查已返回 `ready_for_live_navigation: true`。
- 原厂 32 MB Flash 完整备份并确认校验和后，已完成首次实体设备烧录与启动验证。

## 尚不能声称完成的门槛

当前 Mac 已安装完整 Xcode，最新版 App 已签名、安装并在当前 iPhone 启动；以下实体门槛仍待完成：

1. 验证 CO5300 长时间刷新、CST9217 全边缘触摸、亮度、帧率和温度。
2. 长时间验证 BLE 配对、锁屏后台、主动断电恢复、偏航重算和周期路况刷新。
3. 实测 PWR 长按关机在 USB、电池及 USB+电池三种供电组合下的行为。
4. 验证车把固定、强光可读性、震动和安全交互。
5. 产品化前开通并验证高德交通态势高级 API，取得车载/智能硬件投射与所需数据使用方式的书面授权。
