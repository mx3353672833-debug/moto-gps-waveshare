## iPhone 原生界面

- 主要流程为「出发 → 路线 → 导航中」，使用原生导航栏和分组列表。
- 支持系统浅深色和 Dynamic Type 大字体，圆屏连接状态与详情放在「我的圆屏」。
- 保留真实地点搜索、最近地点、路线预览及候选选择；首页可以直接进入演示。
- 演示的位置和行驶过程明确标为模拟；优先请求固定济南场景的在线路线，失败后使用内置路线。
  真实导航使用手机定位，不会自动回退到演示位置或演示路线。

## 默认在线地图与离线下载

配置可用网关后，周边道路与建筑默认在线加载，来源为 OpenStreetMap / Protomaps。
手机保存地图并筛选当前位置附近的窗口，再通过 BLE 同步给圆屏。

| 入口或能力 | 当前行为 |
| --- | --- |
| 自动周边地图 | 随位置加载、缓存；网络不可用时使用已有本地数据 |
| 下载城市地图 | 搜索城市或区县，预览行政范围后下载 |
| 下载这条路线周边 | 选好路线后保存沿途约一公里范围的底图 |
| 下载管理 | 支持暂停、继续、删除及清理自动缓存 |
| 手机存储预算 | 自动缓存 128 MB，手动下载 512 MB；重复瓦片只保存一份 |
| 济南基础地图 | 原有随包 SQLite 地图继续作为其覆盖区域内的兜底 |

离线下载保存的是道路和建筑背景。地点搜索、新路线规划、联网偏航重算和实时路况仍依赖网络。
地图覆盖密度取决于源数据；没有数据的区域不会补画虚构道路或建筑。
圆屏每个窗口仍受道路、建筑数量与点数限制，不能据此保证全国完整覆盖或成熟导航产品的显示效果。

后端增加瓦片缓存、城市边界查询、并发与请求大小限制，以及独立的地图/城市请求限流。
同一瓦片的并发请求会合并，数据源临时不可用时保留已有缓存。
长期部署应使用稳定且获准使用的数据源，保留 OSM 署名与许可入口。

## BLE、隐私与发布准备

- BLE 心跳改为当前应用会话的已用时间，重连开启新会话时重新计时；手机系统启动时长只用于本地计时逻辑，不再写入心跳载荷。
- 补充 `PrivacyInfo.xcprivacy`，覆盖当前数据类型及所用的 UserDefaults、文件时间戳、系统启动时间 API 声明。
- 新增「隐私与数据」页面，说明定位、路线、蓝牙、音乐、地图缓存及服务器日志的数据处理；没有圆屏也能查看。
- 准备 0.3.0（5）发布配置和审核材料。实际分发前仍需完成开发者账户、构建上传及审核步骤。

自行部署或修改服务时，需按实际服务器日志、数据保留和隐私政策重新核对隐私声明。
本仓库不包含开发者账号、证书、设备标识或私人审核联系人。
