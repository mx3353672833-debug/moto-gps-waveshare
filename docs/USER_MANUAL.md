# MOTO GPS 微雪版功能与使用说明书

本说明对应仓库当前 Waveshare 1.75C 固件和 iOS App。首次制作请先看
[购买与安装教程](WAVESHARE_DIY_GUIDE.md)，服务配置见[路线网关教程](GATEWAY_SETUP.md)。

## 1. 手机与圆屏分别做什么

iPhone 负责位置、搜索、路线预览和导航计算；圆屏通过蓝牙显示导航、速度和航向，并回传触摸操作。
正常使用需要手机在附近。真实搜索、路线规划和重算使用手机网络，不要求开启个人热点。
自研主板方案中的独立 GNSS 和热点联网不属于本说明的微雪版。

出发前在手机上选好路线，圆屏用于查看下一动作和距离。当前路线源是普通驾车接口，
不承诺自动避开摩托车禁行；调试与操作请停车后进行。后台重连和部分路线问题仍在验证，
详见[已知问题](KNOWN_ISSUES.md)。

## 2. 开机、连接与关机

给设备上电，圆屏播放黑底白色 MOTO GPS 启动画面。打开 iPhone 上的 MOTO GPS，
App 自动扫描设备；首次连接按 iOS 提示配对并授权蓝牙。

| 圆屏状态 | 含义 | 下一步 |
| --- | --- | --- |
| 等待手机 / CONNECT PHONE / WAITING FOR PHONE | 未建立可用手机会话，文案随固件版本略有差异 | 打开 App，检查蓝牙权限，靠近设备 |
| CONNECTING / 正在建立连接 | 正在发现服务和完成握手 | 等待；长时间不变时在 App 查看错误并重试 |
| CONNECTED / 连接成功 | 短暂的连接成功提示 | 随后进入准备出发或导航 |
| READY TO RIDE / 请在手机选择目的地 | 已连接，没有正在显示的路线 | 在手机选择终点 |
| BUILDING ROUTE / 正在规划路线 | 正在取得路线 | 等待手机返回；失败时看手机提示 |
| 导航画面 | 已收到有效导航状态 | 查看所选路线与下一动作 |

这些状态不一定在每次操作时全部停留显示；路线预览也可能在圆屏保持准备出发时完成。
手机的物理蓝牙连接和完整协议握手是两个阶段，应以 App 与圆屏都准备就绪为准。

停止使用时，先在 App 结束导航，再持续按住设备 PWR 约 3 秒请求软件关机。
固件还配置了约 4 秒的 PMIC 硬件长按兜底；USB、电池、组合供电的实际掉电/唤醒表现仍待全面验收。
再次上电按微雪设备说明操作。BOOT 是下载/调试按键，不是切页或日常关机按钮。

## 3. 搜索与最近地点

进入“选择目的地”，在“你要去哪里？”输入至少两个字，例如商场、车站或地址。
App 会短暂等待输入稳定后搜索，不必每输入一个字就重复点击。

有手机位置时，结果优先考虑附近地点；附近没有结果时回退到区域/全国搜索。
定位未授权或暂不可用时，界面会说明搜索范围，不能把所有结果理解成附近。
同名地点请结合城市、地址与距离确认，再点“选为终点”。

“最近搜索”最多保存 8 条地点，点选可以再次规划；“清空”移除最近记录。
保存的是地点，不是永久缓存的实时距离或旧路线。选错终点时用“更换”返回重新选择。

## 4. 查看候选路线并开始导航

选择终点后，App 显示“正在生成可选路线”，随后进入“路线全览”。
全程地图和候选卡片最多列出 3 条路线，每条包含预计用时、里程和路况摘要。
返回 1 条或 2 条也是正常结果，不会为了凑数虚构路线。

1. 先确认地图两端的位置和选中的目的地。
2. 点不同的候选卡片比较路线；“全程”用于回到全程视角。
3. 确认选中路线，再点“开始导航”。仅选地点或浏览候选时不会提前把路线作为活动导航发送给设备。
4. 开始后查看手机导航状态及圆屏的白色路线、动作和距离。
5. 如果提示“路线没有生成”，使用“重试”，并检查定位、网关与网络。

当前首次导航使用所选候选，后续偏航和路况更新可能请求新路线。
已记录部分跨城路线和预览一致性问题，遇到明显绕路应停止依赖该结果并记录复现条件。

## 5. 圆屏导航页怎么读

| 画面元素 | 表达的内容 |
| --- | --- |
| 中间车辆箭头 | 当前车头方向参考；地图围绕它移动和旋转 |
| 白色线 | 当前选中的导航路线 |
| 灰色道路与建筑 | 周围环境参照，由手机发送局部底图窗口 |
| 左转、右转、掉头等图标 | 下一个导航动作 |
| 大号数字与 m / km | 距离下一个动作的位置；不是圆屏与手机的蓝牙距离 |
| 圆周路线进度 | 有有效路线时的行程推进提示 |
| 限速牌 | 仅存在可信限速数据时显示；不出现不代表道路不限速 |

无有效路线时，动作、距离、进度和限速隐藏，避免显示旧引导。
路线推进、偏航确认、重算和到达状态由手机更新；GPS 短暂漂移不一定立刻触发重算。
路况按共享核心周期刷新，网络恢复后可能重新获取路线，它不是每一秒都实时更新的路况流。

灰色底图当前内置济南数据。济南以外可能只有选中白色路线，没有同等道路/建筑背景；
这不代表该城市一定不能规划路线。离线底图也不提供全国离线搜索与路线计算。

## 6. 马表、航向和触摸

圆屏左右滑动切换页面。左滑按导航 → 马表 → 航向 → 音乐循环，右滑反向；
未启用音乐能力时跳过音乐页。页面指示点在触摸/换页后出现，约 5 秒无操作收起。
使用较明确的横向滑动，在圆屏中部操作更容易识别。

马表页显示速度和 `km/h`。速度依赖有效定位或演示输入，不等于车辆原厂仪表标定结果。
手机没有提供有效数据时，不把保留画面当成最新速度。

航向页显示角度和八方位，行驶时以手机定位航向作参考，板载传感器辅助相对转向。
QMI8658 没有磁力计，因此停车原地转动设备时不能把它当作已标定的真北指南针。

当前屏幕长按不会开启本机演示。旧版本记录中的长按演示行为已经取消。

## 7. Apple Music 控制

先在 iPhone 的系统“音乐”App 播放一首当前账号可播放的歌曲，允许 MOTO GPS 访问媒体资料库，
再回到 MOTO GPS 并连接圆屏。音乐页可以显示曲目状态和使用以下按钮：

| 操作 | 结果 |
| --- | --- |
| 上一首 | 向系统“音乐”播放器发送上一首命令 |
| 播放 / 暂停 | 切换当前播放状态 |
| 下一首 | 向系统“音乐”播放器发送下一首命令 |

圆屏是遥控器，不负责下载歌曲、传输音频或替代耳机。是否可播放取决于手机的音乐来源、账号、
授权与播放队列。当前不支持网易云等第三方播放器的通用控制，也不提供收藏/喜欢操作。
按钮没反应时先检查手机“音乐”App 本身是否能播放，再检查媒体权限和 BLE 状态。

## 8. 演示导航与结束导航

在手机首页点“演示导航”。演示使用济南大数据产业基地 D 栋附近到浪潮总部附近的场景，
在线优先请求当次路线，失败时回退到内置 OSM 轨迹。进入后手机持续显示“演示”，
屏幕上的移动、速度和距离属于模拟输入。

演示适合桌面检查转弯、触摸、地图和连接。它不能证明真实道路精度、锁屏后台或实时路况可用。
要使用真实目的地，先点“结束导航”退出演示，再重新搜索、选择路线和开始。

真实导航到达后查看手机“已经到达”提示，并点“结束导航”结束当前会话；中途也可手动结束。
停止后请确认圆屏退出活动路线状态。退出手机前先结束不再需要的导航，以免继续消耗定位和电量。

## 9. 锁屏、断网与断开连接

App 配置了后台定位与 BLE，但当前版本仍有离开原网络环境后等待手机、后台恢复等已知问题。
首次使用先做短时间静止验证，再逐步延长；不要用一次成功推断长时间稳定。

| 情况 | 建议操作 |
| --- | --- |
| 手机锁屏后圆屏停止更新 | 停车后打开 App，看前台是否恢复；检查定位“始终”、精确位置和蓝牙权限 |
| 手机无网络 | 线上搜索/规划/重算会受影响；不能认为内置济南底图会替代路线服务 |
| 圆屏断电或超出蓝牙范围 | 重新上电、靠近手机，等待重连；卡住时在 App 使用“重试” |
| 强制结束 App | 定位和连接可能停止，需要重新打开；不要依赖强制结束后的自动恢复 |
| 更换手机或出现旧配对问题 | 先关闭原手机 App/连接；按实际系统提示处理旧配对，不随意擦除整片 Flash |

## 10. 第一次使用的检查表

- [ ] App 能在自己的实体 iPhone 上正常打开，签名有效。
- [ ] 圆屏上电后可连接，App 和圆屏状态一致。
- [ ] 演示可开始、切页和结束，退出后不会继续显示演示路线。
- [ ] 已换成自己的 HTTPS 网关，能搜索真实地点并取得路线。
- [ ] 候选终点、所选路线与开始后的导航一致。
- [ ] 已检查短时锁屏、设备重启、手机网络切换后的恢复情况。
- [ ] 准备使用的音乐按钮在手机和圆屏上都验证过。
- [ ] 电源线和固定件在实际安装位置可靠，不妨碍车辆操作。
