## 本次冻结内容

- V3 外观：连续深灰铝前框、四颗对角外露功能螺钉、圆形黑色玻璃、右侧按键、6 点琥珀色定位标。
- 主体包络：`Ø61 × 16 mm`；含佳明卡口总厚约 `19 mm`。
- 背面安装：Garmin Edge 设备侧四分之一转公卡榫，目标为直接装入佳明底座。
- 佳明 A0 卡口：导向柱 `Ø24.9 × 3.0 mm`，卡榫回转包络 `Ø28.6 mm`，卡榫宽 `11 mm`、厚 `1.5 mm`。
- 圆屏软件：导航、马表、指南针、音乐四页；共享 C/C++、NavCore、LVGL 和 WebAssembly。
- 导航路径：手机负责热点和目的地输入；终端使用独立 GNSS、IMU 和罗盘持续导航，并通过热点获取高德路线、路况和偏航重算。
- H0175 EVT A1 主板：由完整 `Ø52 mm` 四层 R4 路由基线派生，首板主控为 `ESP32-S3-WROOM-1U-N16R8`，集成 LC76GABMD、QMI8658A（C3021082）、IIS2MDCTR（C2655002）、充电/升降压、USB-C 和 31 Pin 屏幕接口。QMI8658A 与 IIS2MDC 属 EVT 受控替代，须分别完成器件 ID/中断/轴向回归及最终装壳装车标定。
- SW1–SW4 使用 EVQP7C01P（C388883）；执行部为 `1.1 ± 0.1 mm`，外壳按键柱预压、完整行程和复位以实物验证为准。
- J1 的官方 MPN 是 `U262-161N-4BVC11`；KiCad footprint 历史名仍含 `16XN`，该历史库名不得用作采购 MPN。
- H0175 EVT A1 按受控屏幕 PDF 第 7 页由 `3V3_DISPLAY` 直接给 TP3.3/IOVCC/VCI/VBAT/VCI_EN 供电；没有加入未经验证的 4 V 选择器，首板必须通过冷启动、低温和最大亮度测试。

## 重要边界

- 当前版本已经不是空白 PCB 骨架，而是完整、已布线并通过 ERC/DRC 的 H0175 EVT A1 电气工程候选；但它仍标记为 `NOT FOR FABRICATION`，不是可直接上传下单的生产签发包。
- Garmin 官方公开了 Edge 四分之一转兼容体系和安装方式，但未公开完整生产公差。锁止槽、导入圆角和注塑缩水必须以原装 Garmin P/N `010-11430-00` 底座实物量规冻结。
- H0175 EVT A1 已生成审阅用 Gerber、钻孔、BOM 和 CPL，但实物、封装、电源、RF、库存复查或代采门槛尚未全部关闭，发布脚本会故意拒绝生成正式下单 ZIP。
- 屏幕、电池、GNSS 天线、FPC、USB、密封、QMI8658A 固件、IIS2MDC 罗盘、EVQP7C01P 按键、热点、温升、防水和装车振动均需实物验证。
- 未测试前不宣称 IP67、续航小时数、GNSS 精度、罗盘精度或全部第三方佳明底座兼容。
