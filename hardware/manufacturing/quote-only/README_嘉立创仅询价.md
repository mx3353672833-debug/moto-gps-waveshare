# 嘉立创仅询价说明

上传文件：`MOTO_GPS_RevA0_R4_仅询价_DO_NOT_ORDER_Gerber.zip`

这个 ZIP 只用于嘉立创 PCB 页面识别板框、层数并查看裸板价格。它来自
Rev A0 R4 的同一套审阅 Gerber/钻孔文件，但尚未完成实物、电源、RF、
封装和采购放行，因此**不要提交订单、不要付款、不要转入 PCBA 生产**。

上传后应核对：

- 层数：4 层；
- 外形：约 52 × 52 mm 的圆形异形板，四处有螺钉柱月牙避让；
- 板厚询价选择：1.0 mm；
- 表面处理询价选择：沉金；
- 数量可先选 5 片查看价格。

如果预览识别成 2 层、矩形板、尺寸明显不是约 52 × 52 mm，立即停止，
不要继续报价或下单。

只看裸 PCB 价格不需要 BOM/CPL。若只想试算贴片费用，可另外查看 R4
审阅包内的 `documents/engineering-bom-review.csv` 和
`documents/engineering-cpl-review.csv`，但其中仍有 28 个实物/验证/采购
门槛，当前结果只能当估价，不能当可生产物料单。
