## 本轮已经完成

- 屏幕冻结为华夏彩光 `H0175Y003AMT003 V1`，1.75 英寸、466 × 466、CO5300 QSPI、CST820 单点触控。
- J3 使用 `C5343228 / XUNPU FPC-0.3FX-31PWBH10` 候选座。现有逻辑映射为 `屏幕 pin = 32 - J3 pad`；实物屏、排线与两端连接器的连续性仍是最终依据。
- 屏幕 `TP3.3 / IOVCC / VCI / VBAT / VCI_EN` 在 A1 中全部由滤波后的 `3V3_DISPLAY` 供电。供应商受控资料第 7 页明确允许 VBAT 3.3 V，因此首板采用最少器件方案；资料中另有 3.7–4.5 V 的矛盾描述，必须在实屏上验证低温、高亮和冷启动。
- IMU 改为 `QMI8658A / C3021082`，沿用已审核的 14-LGA 焊盘。A/C 的封装、逐脚定义、WHO_AM_I 与寄存器图一致，作为 EVT 受控直替；固件仍需回归 ID、两路中断、轴向和量程。
- 磁力计改为 `IIS2MDCTR / C2655002`。当前电路只使用 I2C，因此与原 LIS2MDL 接法兼容；固件和整机铝壳中的校准仍需实测。
- 四只按键改为 `EVQP7C01P / C388883`。电路焊盘、按力、高度和行程匹配；执行部比原 K 版低约 0.1 mm，按键柱预压必须在壳体样件上验证。
- USB-C `C319148` 的正式 MPN 修正为 `U262-161N-4BVC11`。项目 footprint 文件名中的 `16XN` 是历史名称，实际焊盘按 C319148 审核。
- R19 改为 `5.23 kΩ / C477746`；GNSS RF ESD 改为 `LESD8LL5.0CT5G / C2987702`、SOD-882、最大约 0.3 pF。
- 板框与 V3 四螺钉外壳统一：PCB 名义 Ø52 mm，螺钉轴 PCD 55.40 mm，底座保留佳明四分之一转卡口。

## 现在仍不能直接付款投产的原因

1. 收到实屏后，必须确认屏端连接器、31P 排线的同面/异面、金手指厚度、Pin 1 和 GND 连通关系；未确认前，插错一次就可能直接损坏屏幕。
2. 屏幕 3.3 V 方案需要做限流上电、低温、高亮白屏和反复冷启动测试。
3. USB-C、排线、按键、电池、天线和壳体 Z 高需要实物闭环；当前 3D 模型并不覆盖全部自建封装。
4. `BQ25628E + TPS63070` 电源链需先做冷启动、充放电切换、1.5 A 负载阶跃和密封温升测试。
5. LC76G 的 3 mm 周边间距是 Quectel 为焊接与返修提出的 DFM 建议，不是 RF 电气间距；A1 的 L3/R33 等近端 RF 匹配件无法同时满足它。5 片 EVT 只有在嘉立创明确接受局部 DFM/返修豁免后才可贴装，量产 Rev B 再重排。GNSS 50 Ω/天线、ESP32 外置 2.4 GHz 天线和整机 RF 仍属放行门槛。
6. QMI8658A、IIS2MDC、EVQP7C01P 属 EVT 受控替代，需在首板上完成固件/机械回归。
7. 下单当天还要在嘉立创页面重新核对库存、最小贴装量和替代料，禁止勾选自动替换关键芯片。

## 实屏到货后的最短动作

1. 不上电，万用表确认屏幕多组 GND、Pin 1 和 31P 排线端到端关系。
2. 卡尺记录排线厚度、接触面、插入方向、屏幕总厚度和连接器高度。
3. 用限流电源验证 3.3 V 屏幕启动；先黑屏/低亮，再高亮白屏与触控。
4. 将实测值回填到 J3/外壳；重跑 ERC、DRC、BOM/CPL 和 Gerber 导出。
5. 只有所有物理门槛关闭后，生成正式的 `FOR_FAB` 嘉立创 PCB+SMT 包。
